# 물고기 3D 에셋 생성 지침 (Codex용)

이 문서는 `aquarium` 노션 위젯에 들어갈 **로우폴리 PSX 감성 물고기 3D 모델**을 만들 때
지켜야 할 규격이다. 아래 "계약(Contract)"을 정확히 지키면 위젯 코드에 그대로 꽂힌다.

---

## 0. 한 줄 요약
> PSX/N64 감성의 **로우폴리 열대어**를 종별로 1마리씩 `.glb`(바이너리 glTF)로 만들어,
> `assets/fish/` 폴더에 정해진 이름으로 저장한다. **머리는 +Z, 위는 +Y, 몸길이=1.0 단위, 원점=몸통 중심.**

---

## 1. 저장 위치 & 파일명 (계약)
- 폴더: `C:\Users\hyein\notion-widgets\aquarium\assets\fish\`  (없으면 생성)
- 형식: **`.glb`** (binary glTF 2.0, 텍스처 임베드). `.gltf`+분리 파일 금지.
- 파일 1개 = 물고기 1종 = 메쉬 1마리. (떼로 묶지 말 것)
- 파일명(소문자, 케밥): 아래 중 필요한 것
  - `clownfish.glb`  (주황+흰줄 흰동가리)
  - `blue-tang.glb`  (파란 양쥐돔)
  - `yellow-tang.glb`
  - `guppy.glb` / `neon-tetra.glb` / `angelfish.glb` 등 자유 추가
- 위젯은 파일명을 보고 마릿수·종류를 배치하므로, 새 종을 추가하면 알려줄 것.

## 2. 좌표·스케일 규격 (★가장 중요 — 틀리면 거꾸로 헤엄침)
- **전방(머리 방향) = +Z**  → 위젯이 `lookAt`으로 진행방향을 +Z에 맞춘다.
- **위 = +Y**, 오른쪽 = +X.
- **원점(0,0,0) = 몸통의 정중앙.** (머리-꼬리, 위-아래, 좌-우 모두 가운데)
- **몸길이(코끝→꼬리끝) = 정확히 1.0 단위.** 위젯에서 종마다 0.4~0.7로 다시 스케일한다.
- 모든 트랜스폼은 **적용(apply/freeze)** 해서 내보낼 것. (스케일/회전 잔여값 0)

> 검증: https://gltf-viewer.donmccurdy.com 에 올려 머리가 +Z(뷰어 기본 카메라 기준 화면 안쪽/앞)를
> 향하고, 바운딩박스 길이가 ~1인지 확인.

---

## 3. 스타일 규격 (PSX 로우폴리)
- 폴리곤: **삼각형 150~400개** 수준. 각지고 단순하게(저폴리).
- 셰이딩: **플랫(faceted)** 선호. 부드러운 스무딩 X.
- 색/텍스처 둘 중 하나:
  - (간단) **버텍스 컬러 또는 단색 머티리얼** — 텍스처 없이 색 면으로.
  - (질감) **저해상도 텍스처 64×128px** 정도, **니어레스트(점) 샘플링**, 밉맵/안티앨리어싱 없이.
    텍스처는 작고 도트 느낌이어야 함(고해상 사실적 텍스처 금지).
- 흰동가리는 **주황 몸 + 흰 세로줄 2~3개**(줄은 색면/텍스처로). 눈은 작은 검은 점.
- 지느러미(등·가슴·꼬리)는 **얇은 단면 면(double-sided)** 으로. 두껍게 모델링하지 말 것.

---

## 4. 애니메이션·노드 (선택 — 있으면 더 살아있음)
- **꼬리 스위시용 노드(권장):** 꼬리지느러미를 별도 자식 노드로 분리하고
  노드 이름을 정확히 **`Tail`** 로. 위치는 꼬리 시작점(대략 z ≈ -0.35). 피벗이 그 지점에 오게.
  → 위젯이 `Tail.rotation.y`를 좌우로 흔든다. (없으면 위젯이 몸 전체를 살짝 까딱이게 처리)
- **베이크 애니메이션(선택):** 헤엄치는 루프 클립을 넣을 거면 클립 이름 **`Swim`** (1~2초 루프).
  넣으면 위젯이 자동 재생. 없으면 위젯이 절차적으로 흔든다.
- 카메라·라이트·빈 컬렉션은 파일에 **넣지 말 것.** 메쉬(+선택적 Tail 노드)만.

## 6. 제작 방법 (Codex가 택1)
A. **Blender Python 스크립트**로 메쉬 생성 → `bpy.ops.export_scene.gltf(format='GLB')`.
   (스크립트도 같이 커밋해두면 재생성 가능)
B. **three.js + GLTFExporter** Node 스크립트로 지오메트리 만들어 GLB로 export.
C. **AI 3D 생성툴(Meshy/Tripo 등)** 결과를 GLB로 받아 위 §2 규격대로 정렬·스케일 후 저장.

> 어떤 방법이든 **최종 산출물은 §1~§4 규격을 만족하는 `.glb`** 다. 방법은 자유.
